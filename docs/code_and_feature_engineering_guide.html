02 · Architecture

The code is a small sequence of ordinary steps

1. Build rowsJoin draft, Combine, NCAA, and NBA tables at the intended player-year grain.
2. Materialize featuresCompute rates, deltas, nonlinear terms, and composites once in parquet.
3. Read JSONChoose the target, inputs, years, preprocessing behavior, and XGBoost parameters.
4. Fit in timeFit preprocessing and the model only on chronologically eligible rows.
5. Save evidenceWrite the fitted artifact, metrics, predictions, and search results.
Training2009–2017
Validation2018–2019
Holdout2020–2022

For the final frozen run, the estimator is refitted through 2019. Only 2020–2022 remains out of sample.

Where responsibilities live

Classification
train_classifier.py handles command-line orchestration and files → classifier_workflow.py contains validation, preprocessing, calibration, annual ranking, evaluation, and artifact helpers → tune_classifier.py owns the search loop.
Regression
train_model.py contains the compact regression workflow → tune_model.py reuses its functions across expanding validation folds → tuning.py builds reproducible candidates for both tasks.
Why this organization is useful. The command-line scripts read like recipes. Reusable pieces are plain functions, so notebooks and tests can call the exact same logic without duplicating a hidden second implementation.
03 · Regression walkthrough

From a drafted player to a minutes prediction

  1. Load the frozen JSON. It names the advanced parquet, target, 48 features, chronological split, XGBoost parameters, and output file.
  2. Validate and clean. Rows missing the target or split year are dropped. Configured numerical columns are coerced to numbers; infinities become NaN.
  3. Split by draft year. The test period is later in time, not a random sample of older players.
  4. Fit preprocessing. Each numeric column receives a training-fold median, then standardization. The winner has no categorical inputs.
  5. Fit XGBoost. The target remains raw minutes because log_transform_target is false.
  6. Refit and evaluate. The final model fits train + validation, predicts all three named periods, and saves a normal sklearn pipeline with joblib.
config = load_config("configs/xgboost_minutes_advanced_best.json")
data = prepare_data(load_data(config["data_path"]), config)
splits = split_data(data, config["split"])

model = make_pipeline(config)
fit_rows = concat(splits["train"], splits["validation"])
model.fit(fit_rows[features], fit_rows["nba_min_3y"])
test_minutes = model.predict(splits["test"][features])

Frozen XGBoost settings

SettingValuePlain-language role
n_estimators / learning_rate500 / 0.02Many small corrections rather than a few aggressive trees.
max_depth1Decision stumps keep individual relationships deliberately simple.
min_child_weight10Discourages splits supported by very little effective sample weight.
subsample / colsample_bytree1.0 / 0.8Use all rows but only 80% of columns for each tree.
reg_alpha / reg_lambda100 / 25Strong L1 and L2 regularization limits unstable leaf values.
gamma200,000Requires a large squared-error improvement before adding a split. Its scale looks large because the target is raw minutes.
One subtlety: trees do not require standardized inputs, but this project’s generic regression pipeline scales them consistently. The scaler and median values are learned only from rows used in each fit, so they do not inspect the holdout.
04 · Classification walkthrough

From a Combine row to a calibrated annual rank

  1. Validate the modeling grain. The workflow requires one row per (nba_player_id, draft_year), a binary target, and every configured input.
  2. Reject leakage. IDs, names, draft results, absolute calendar columns, linkage metadata, and post-draft nba_* fields cannot be configured as predictors.
  3. Prepare inputs. Numeric values and NaN pass directly to XGBoost. Missing positions become the literal category missing, then positions are one-hot encoded.
  4. Fit a calibration model. A train-only XGBoost model scores 2018–2019; logistic regression maps its log-odds to calibrated probabilities.
  5. Refit the estimator. XGBoost is fitted through 2019 after removing earlier rows for players who reappear in the 2020–2022 holdout.
  6. Rank within each year. The frozen operating rule labels the top 63.0137% of the complete participant batch in each year.
  7. Save a bundle. The joblib artifact contains the estimator, calibrator, decision rule, and feature schema together.
config = load_config("configs/xgboost_draft_classifier_advanced_best.json")
data = prepare_data(load_data(resolve(config["data_path"])), config)
splits = chronological_splits(data, config["split"])

model, calibrator, rule, fit_info = fit_configured_classifier(config, splits)
metrics = evaluate(model, splits["test"], features, "drafted",
                   calibrator=calibrator, decision_rule=rule,
                   year_column="draft_year")

Frozen XGBoost settings

SettingValuePlain-language role
n_estimators / learning_rate400 / 0.035Build a conservative score in many small steps.
max_depth / min_child_weight1 / 3Use shallow effects and avoid tiny leaves.
subsample / colsample_bytree0.65 / 0.8Sample rows and columns to reduce variance.
reg_alpha / reg_lambda0 / 3No L1 penalty; moderate L2 shrinkage.
gamma / max_delta_step0.5 / 1Demand useful splits and limit abrupt logistic updates.
scale_pos_weight0.3Downweights the positive class; chosen on pre-test validation folds.
The annual class label is a batch decision. It only makes sense when scoring the complete Combine-participant set for a year. For one isolated player, use the calibrated probability or ranking score—not the annual top-fraction label.
05 · Feature engineering

Turn raw box scores into comparable basketball signals

The main idea is simple: totals reflect opportunity as much as ability. Per-minute rates, efficiency measures, career summaries, and development features make different prospects more comparable while preserving what was actually observed.

Per-40 production

40 × statistic ÷ minutes

Normalizes points, rebounds, assists, steals, blocks, turnovers, and attempts to a common playing-time scale.

both models

Shooting efficiency

eFG% = (FGM + 0.5 × 3PM) ÷ FGA TS% = PTS ÷ [2 × (FGA + 0.44 × FTA)]

Credits the extra value of threes and accounts for free throws.

both models

Playmaking and shot profile

AST/TOV · 3PA/FGA · FTA/FGA

Describes ball security, perimeter orientation, and ability to reach the line.

both models

Reliable career summaries

sum career totals first, then recompute rates

This weights seasons by their real minutes or attempts instead of averaging small and large samples equally.

both models

Basketball composites

FeatureFormulaWhy it exists
Stockssteals per 40 + blocks per 40A compact defensive-event measure.
Playmaking marginassists per 40 − turnovers per 40Balances creation against lost possessions.
Production indexPTS + REB + AST + 2(STL + BLK) − TOV, all per 40Provides a broad, intentionally transparent production summary.
Usage proxyFGA + 0.44 × FTA + TOV, all per 40Approximates possessions a player finishes or turns over.
Shrunk 3P%(3PM + 0.35 × 40) ÷ (3PA + 40)Pulls tiny shooting samples toward a fixed 35% prior.
Shrunk FT%(FTM + 0.72 × 30) ÷ (FTA + 30)Pulls tiny free-throw samples toward a fixed 72% prior.
Safe division rule. A zero denominator, infinity, or undefined rate becomes missing—not zero. “No usable attempt sample” is different from “made 0%,” and the model should keep that distinction.
05 · Feature engineering continued

Age, development, Combine traits, and draft capital

Age and upside

centered age = age − 21 youth score = 23 − age age-adjusted output = youth × production

Exposes nonlinear age effects and the interaction between current output and development runway.

Combine-derived traits

wingspan − height · standing reach − height max reach = standing reach + max vertical BMI = 703 × weight ÷ height²

Separates functional length, explosiveness, and mass-for-height from raw measurements.

Recent development

classifier delta = last season − previous season regression difference = last season − career regression ratio = last season ÷ career

Captures direction of change. The three definitions are related but not interchangeable.

Nonlinear draft capital

log(1 + pick) · √pick · 1/pick · pick² pick ≤ 5 · 10 · 14 · 30

Represents the steep, nonlinear connection between team investment and early NBA opportunity.

regression only

Documentation fields are intentional. Descriptions, evaluation notes, and feature-selection provenance do not change XGBoost. They travel with the experiment so a future reader can understand what was selected, when it was selected, and which claims are clean holdout evidence.
07 · Experiment discipline

Keep frozen winners separate from new searches

Frozen reference

A checked, named configuration whose parameters and reported holdout result should not change.

*_advanced_best.json

Use it for reproduction, the toy notebooks, and comparison.

Search output

A new experiment produced by tuning. It may be better or worse and needs its own filenames.

*_advanced_search_best.json

Inspect validation evidence before deciding whether to promote it.

What each tuner now does

Regression tunerClassification tuner
Validation designThree expanding windows: 2014–15, 2016–17, 2018–19.Six expanding annual folds: 2012 through 2017.
Selection scorePooled out-of-fold RMSE; lower is better.Mean annual normalized AP; higher is better.
Candidate sourceConfigured fixed candidates plus a reproducible sample from the search lists.Configured fixed candidates plus a reproducible sample from the search lists.
Leakage controlEvery fold ends before its validation years; test years are rejected.Same chronological control, plus repeated-player purging.
ProtectionBoth scripts refuse to write best_config_path
For classification year y: normalized AP = (APy − prevalencey) ÷ (1 − prevalencey). This gives random/prevalence-level ranking a baseline of zero and a perfect ranking a score of one before averaging years equally. 
# Reproduce the frozen winners
python src/train_classifier.py --config configs/xgboost_draft_classifier_advanced_best.json
python src/train_model.py --config configs/xgboost_minutes_advanced_best.json

# Run small, separate search experiments
python src/tune_classifier.py --config configs/xgboost_draft_classifier_advanced_best.json --n-iter 5
python src/tune_model.py --config configs/xgboost_minutes_advanced_best.json --n-iter 5
A quick search does not redefine “best.” The --n-iter flag temporarily samples fewer candidates for a smoke test. Its output is deliberately written to separate search filenames and should not replace the historical winner merely because the script completed.
08 · Working safely

Common changes and the smallest correct workflow

You want to…ChangeThen verify
Try different XGBoost settingsCopy a config, give its model/results/best-config outputs new names, edit tuning.search_space, and run the tuner.Compare pre-test validation first. Treat 2020–2022 as confirmation, not the selector.
Add an existing parquet columnAdd its exact name to the numerical or categorical list in an experiment config.Confirm timing and leakage safety; rerun chronological tuning.
Create a new feature formulaImplement it in the appropriate dataset builder/materializer, rebuild the advanced parquet, then configure it.Check undefined denominators, missingness, units, and whether the formula uses only information available at prediction time.
Switch estimator familiesRegression accepts Ridge/XGBoost; classification accepts logistic regression/XGBoost.For logistic classification, use median imputation because logistic regression cannot consume native NaN.
Move the evaluation yearsUpdate the split only after confirming the parquet contains those years.Keep a genuinely later, untouched final period and rebuild all validation folds.
Score new classifier rowsUse the saved bundle’s schema, estimator, and calibrator.Only apply the annual class rule to a complete yearly participant batch.

A good experiment checklist

  • Copy the frozen config instead of editing it in place.
  • Choose new output filenames before running anything.
  • Write one sentence describing the hypothesis behind the change.
  • Keep target, population, and split fixed when comparing feature or parameter choices.
  • Use validation to choose; inspect test only after the choice is frozen.
  • Save the resulting config and metrics together.
  • Run python -m unittest discover -s tests -v.
Human-readable code habit: comments should explain why a step exists—leakage prevention, timing, missingness, or basketball meaning. The function and variable names should explain what the code mechanically does.
09 · Debugging

When something goes wrong, start with the contract

SymptomLikely causeWhat to inspect
“Columns not found” or “Dataset is missing columns”The JSON and parquet schemas do not match.Spell the feature exactly, verify data_path, and rebuild the advanced table if the feature is new.
“Outcome or identity fields cannot be features”The classifier leakage guard found a target, identity, calendar, linkage, or post-draft field.Remove it. Do not bypass the guard to improve a metric.
Duplicate player-year errorThe classification table no longer has one row per event.Fix the upstream join or aggregation; do not silently drop an arbitrary duplicate.
One chronological split is emptyThe configured years are absent or ordered incorrectly.Inspect draft_year coverage and the five split boundaries.
AP or R² suddenly changedA search output was mistaken for the frozen config, data changed, or a different split/model artifact was loaded.Compare hyperparameters and filenames first; then confirm row counts and dependency versions.
.predict() fails on classifier joblibThe advanced classifier is a dictionary bundle, not a bare pipeline.Use artifact["estimator"], its calibrator, and its decision rule—or reuse workflow helpers.
A classifier label changes when other rows are addedThe annual top-fraction rule ranks a batch.This is expected. Probabilities are row-level; annual labels are cohort-level.
Missing values look like zerosA custom preprocessing change may have destroyed missingness semantics.Numeric absence should be NaN; only categorical absence becomes the string missing.

Saved artifact anatomy

Regression joblib

A fitted sklearn Pipeline containing the numeric preprocessor and XGBoost regressor.

model = joblib.load(path)
minutes = model.predict(rows[features])

Classification joblib

A versioned dictionary containing estimator, sigmoid calibrator, decision rule, target, features, and training cutoff.

artifact = joblib.load(path)
model = artifact["estimator"]
rule = artifact["decision_rule"]

Interpretation boundaries

  • The classifier describes players who reached this consistently observed Combine cohort, not every NCAA player.
  • The regression describes drafted players and deliberately includes draft position. It is not a talent-only or fully pre-draft model.
  • Predictions are associations, not estimates of what would happen if a team changed a player’s draft position, role, or development plan.
  • Unresolved NCAA histories remain missing. Native missing handling preserves the gap but cannot eliminate selection bias in who links successfully.
  • Multiple experiments have been viewed on the 2020–2022 period. A future cohort is the appropriate next independent confirmation.
  • For classification, AP and ROC-AUC are the clean frozen ranking claims. The repaired annual decision rule and probability calibration deserve confirmation on future data.
